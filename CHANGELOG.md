# Changelog


## [0.3.0] - 2026-10-21
### Добавлено (Инкремент 3: Сохранение, Undo/Redo, Drawing)
- Создан класс `Drawing` как контейнер для всех объектов рисунка.
- Реализован класс `Settings` для хранения настроек редактора.
- Внедрен паттерн Command для Undo/Redo:
  - Интерфейс `Command` с методами `execute()` и `undo()`.
  - Классы `AddShapeCommand`, `DeleteShapeCommand`, `MoveShapeCommand`.
  - Стек undo/redo в контроллере.
- Добавлено меню "Файл" с пунктами: Новый, Сохранить, Открыть.
- Добавлено меню "Правка" с пунктами: Отменить (Ctrl+Z), Повторить (Ctrl+Y).
- Реализовано сохранение рисунка в файл через Java-сериализацию.
- Реализована загрузка ранее сохранённого рисунка.
- Добавлена обработка ошибок при открытии файлов.
- Все классы фигур реализуют `Serializable` для корректного сохранения.
- Рефакторинг структуры проекта: папки `model/shapes/` и `model/commands/`.

### Исправлено
- Объекты теперь отображаются сразу после клика (добавлен `canvas.requestRedraw()`).
- Декораторы можно накладывать друг на друга (убрана проверка `instanceof Polygon`).
- Перемещение декорированных фигур работает корректно.
- Исправлена ошибка NotSerializableException при сохранении: цвет (Color) теперь корректно сериализуется через целочисленное ARGB-представление.

## [0.2.0] - 2026-10-14
### Добавлено (Инкремент 2: Векторный редактор + Декоратор)
- Реализован интерфейс `Shape` как общий тип для всех графических элементов.
- Добавлен класс `Polygon` для представления векторных фигур по вершинам.
- Внедрен паттерн Декоратор (`ShapeDecorator`) для динамического добавления свойств:
    - `FillDecorator` - заливка полигона выбранным цветом.
    - `BorderDecorator` - контур полигона с настраиваемой толщиной.
    - `ShadowDecorator` - тень со смещением.
- Добавлен инструмент "Полигон" с визуализацией процесса рисования (точки и линии).
- Добавлен инструмент "Выделение / Перемещение" для работы с объектами.
- Реализовано перемещение декорированных фигур (метод `move` в интерфейсе `Shape`).
- Расширен интерфейс: отдельные режимы рисования кругом и квадратом при зажатии мыши.
- Обновлена UML-диаграмма классов (в документации).

### Исправлено
- Восстановлен функционал Инкремента 1: рисование точками, кругами и квадратами кликом и перетаскиванием.
- Устранена проблема невозможности перемещения полигона после применения декоратора.

## [0.1.0] - 2026-10-07
### Добавлено (Инкремент 1: Растровый редактор)
- Реализован абстрактный базовый класс `Pixel` (интерфейс `Shape`).
- Реализованы конкретные классы растровых элементов: `Point`, `Circle`, `Square`.
- Внедрен паттерн Фабрика (`PixelFactory`) для инкапсуляции создания элементов.
- Реализовано рисование мышью (растровый режим через точки) и добавление фигур.
- Добавлена возможность очистки холста.
- Настроена базовая структура Git-репозитория и документация (README, CHANGELOG).
- Написаны Unit-тесты для фабрики и коллекций (покрытие требований T1-T14).
