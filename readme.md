## Памятка для работы с Git

Перед каждым пушем:

```bash
# 1. Перейти в папку проекта
cd "D:\GIGA IDE\GIGA IDE projects\имя проекта"

# 2. Проверить статус
git status

# 3. Добавить все изменения
git add .

# 4. Сделать коммит
git commit -m "описание изменений"

# 5. Запушить
git push
```

Полезные команды:

```bash
# Проверить текущую ветку
git branch

# Проверить привязанный репозиторий
git remote -v

# Посмотреть историю коммитов
git log --oneline
```
