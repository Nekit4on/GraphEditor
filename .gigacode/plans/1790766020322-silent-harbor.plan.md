# План: Добавление Maven Wrapper для GraphEditor

## Проблема
- Maven не установлен в системе (`mvn` не найден)
- JavaFX требует VM options для запуска (`--module-path`, `--add-modules`)
- Класс `Main.java` в default package — не указан package в `<mainClass>` в pom.xml

## Решение

### 1. Создать Maven wrapper (mvnw.cmd)
Создать файлы:
- `mvnw.cmd` — Windows-обёртка для Maven
- `mvnw` — Unix-обёртка (на всякий случай)
- `/.mvn/wrapper/maven-wrapper.properties` — конфигурация версии
- `/.mvn/wrapper/maven-wrapper.jar` — JAR для загрузки Maven

### 2. Настроить pom.xml для JavaFX
- Добавить `<mainClass>Main</mainClass>` (уже есть, но убедиться что работает)
- Убедиться что `javafx-maven-plugin` правильно настроен

### 3. Добавить .gitignore
- Исключить `.mvn/`, `target/`, `*.class`

### 4. Инструкция по запуску
- `mvnw.cmd compile` — компиляция
- `mvnw.cmd javafx:run` — запуск

## Файлы для создания
- `D:/GIGA IDE/GIGA IDE projects/GraphEditor/mvnw.cmd`
- `D:/GIGA IDE/GIGA IDE projects/GraphEditor/mvnw`
- `D:/GIGA IDE/GIGA IDE projects/GraphEditor/.mvn/wrapper/maven-wrapper.properties`
- `D:/GIGA IDE/GIGA IDE projects/GraphEditor/.mvn/wrapper/maven-wrapper.jar`
- `D:/GIGA IDE/GIGA IDE projects/GraphEditor/.gitignore`

## Верификация
1. `mvnw.cmd compile` — проект должен скомпилироваться
2. `mvnw.cmd javafx:run` — приложение должно запуститься
